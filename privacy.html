Kebijakan Privasi ARISAN

Berlaku sejak 24 Oktober 2026

Ringkasnya

ARISAN tidak meminta data pribadi dan tidak membagikannya ke siapa pun. Catatan permainan anonim hanya dikirim kalau kamu memilih untuk membantu bot belajar.

Data yang disimpan di perangkatmu

Nama panggilan yang kamu ketik, pangkat, kue, kosmetik, prestasi, catatan Arisan Harian, dan nama pemain di mode oper HP disimpan di penyimpanan lokal perangkatmu. Data ini tidak pernah dikirim ke mana pun. Kalau aplikasi dihapus, data ini ikut terhapus.

Bantu bot belajar (pilihan)

Setelah permainan pertama, kamu ditanya apakah mau membantu bot jadi lebih pintar. Hanya kalau kamu memilih Ya, bantu, game mengirim catatan permainan ke server kami di Cloudflare. Isinya: hasil permainan, peran, voting, dan pesan yang kamu ketik di grup. Nama anggota dan namamu diganti penanda sebelum dikirim, angka panjang dibuang, dan tidak ada akun, ID perangkat, atau alamat IP yang disimpan. Server hanya menyimpan sidik IP acak per jam untuk mencegah spam, lalu menghapusnya setelah 2 hari. Catatan dihapus otomatis setelah satu tahun. Untuk pesan yang sulit dipahami, server meminta model bahasa di Cloudflare Workers AI membantu memberi label. Yang dikirim hanya pesan yang sudah disamarkan, dengan nama anggota diganti samaran. Catatan ini hanya dipakai untuk melatih bot dan tidak dijual atau dibagikan ke sponsor. Kamu bisa mematikannya kapan saja lewat menu ⋯ → Bantu bot belajar.

Yang tidak kami lakukan

  • Tidak ada akun, login, atau server permainan.
  • Tidak ada analitik pihak ketiga, pelacakan lintas aplikasi, atau jaringan iklan.
  • Tidak meminta izin lokasi, kamera, mikrofon, atau kontak.
  • Tidak ada pembelian di dalam aplikasi. Kue hanya didapat dari bermain.

Konten sponsor

Game ini bisa menampilkan konten sponsor, misalnya kerudung edisi brand atau promo di kocokan arisan, selalu dengan label "Sponsor". Daftar sponsor diunduh sebagai file biasa dari situs kami. Kami tidak mengirim data apa pun tentang kamu ke sponsor, tidak ada pelacakan iklan, dan tidak ada ID perangkat yang dikumpulkan. Kalau kamu menekan "Lihat promo", halaman sponsor dibuka di browser, dan sejak saat itu kebijakan privasi sponsor yang berlaku.

Fitur berbagi

Tombol "Bagikan" hanya membuka menu berbagi bawaan perangkatmu dengan teks hasil permainan. Kamu yang memilih mau dikirim ke mana.

Koneksi internet

Aplikasi bisa dimainkan tanpa internet. Kalau sedang online, aplikasi mengunduh huruf (font) dari Google Fonts. Permintaan itu tidak berisi data permainanmu.

Perubahan dan kontak

Kalau kebijakan ini berubah, versi terbarunya ada di halaman ini. Pertanyaan bisa diajukan lewat halaman Issues di GitHub.
